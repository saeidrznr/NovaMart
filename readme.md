# NovaMart 🛒

NovaMart is a production-oriented e-commerce backend built with FastAPI.

The project is being developed as a practical backend project, covering modern backend development concepts from API design and database management to testing, containerization, and deployment.

## 🛠️ Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Redis
- Celery
- Pytest
- Docker
- GitHub Actions
